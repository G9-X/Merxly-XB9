11. End-to-End Flows

Full Purchase Flow

  1. Guest -> Search san pham -> Xem chi tiet
  2. Click "Add to Cart" -> redirect login
  3. Dang nhap Customer -> quay lai product
  4. Add to Cart -> Mo /cart
  5. Proceed to Checkout -> Chon address + payment
  6. Pay voi the 4242... -> Order confirmed
  7. Kiem tra /user-account/order-history co don hang moi
  8. Login StoreOwner -> /store/orders co SubOrder moi

Store Onboarding Flow

  1. Dang ky tai khoan moi (Customer role)
  2. Navigate toi /sign-up-new-store
  3. Dien form: ten store, CCCD, giay phep, SDT
  4. Submit -> store trang thai "Pending"
  5. Login Admin -> /admin/stores/verification
  6. Xem ho so -> Click "Approve" (commission 5%)
  7. Login lai Customer -> role thanh StoreOwner
  8. Navigate /store -> Store Dashboard hien thi

13. Run Automated E2E Tests

Commands

  1. Chay Docker: docker compose up -d
  2. Vao frontend dir: cd merxly_frontend
  3. Cai dependencies: npm install
  4. Chay full suite: STORE_OWNER_EMAIL=e2e-storeowner@merxly.test STORE_OWNER_PASSWORD=Test@12345 npx playwright test
  5. Xem report: npx playwright show-report

Expected Results

  • 125 tests passed
  • 8 skipped (product-detail, no products in DB)
  • 0 failed
  • Duration: ~2 minutes

Run Specific Suites

  • npx playwright test e2e/specs/auth/
